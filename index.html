Google Maps Zone Builder

실제 Google 지도에서 장소를 검색하거나 지도를 클릭해 Zone 꼭짓점을 만들고, GeoJSON/KML로 내보내는 내부 운영용 MVP입니다.

GitHub Pages 테스트 링크입니다. 상단 입력칸에 Google Maps API key를 붙여넣고 지도 로드를 누르세요. 지도가 안 뜨면 Google Cloud referrer에 https://lsjlwj5371.github.io/groundk-zone-builder/*가 허용되어 있는지 확인하세요.
